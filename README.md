# CakeLuv - Premium Artisanal Bakery & Cake Studio 🎂✨

Handcrafted celebration cakes, bespoke pastries, and custom occasion cakes made with love and the finest ingredients.

## Features
- 🍰 **Artisanal Menu**: Signature celebration cakes, tiered wedding cakes, handcrafted pastries, and seasonal specials.
- 🎨 **Custom Cake Studio**: Interactive cake builder with flavor selection, tier customization, and dietary options.
- 🤖 **AI Cake Concierge**: Powered by Google Gemini AI to help design custom theme cakes and personalized flavor pairings.
- 📱 **Responsive & Modern UI**: Smooth animations, premium aesthetic, and mobile-friendly design.

## Tech Stack
- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS
- **Icons & Animation**: Lucide React, Motion
- **AI Integration**: Google Gen AI SDK (`@google/genai`)

## Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/zaheerjklabs/Bakery-Website.git
   cd Bakery-Website
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Configure environment variables (optional, for Gemini AI features):
   ```bash
   cp .env.example .env.local
   ```
   Add your `GEMINI_API_KEY` in `.env.local`.

4. Start the development server:
   ```bash
   npm run dev
   ```

5. Build for production:
   ```bash
   npm run build
   ```
